# Calgary Driving School Management Portal

An internal receptionist management portal and relational database system built as a university project. 

This application provides administrative staff with a centralized interface to manage student registrations, schedule lessons, log payments, update statuses, and generate real-time business intelligence reports.

## Tech Stack
* **Backend / UI:** Python, Flask, HTML5, CSS3
* **Database:** PostgreSQL (Cloud hosted on Neon)
* **Programmability:** Stored Procedures (`sp_BookLesson`, `sp_RecordPayment`), Automated Triggers, and Analytical Views.
